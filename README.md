# 台股每日主力籌碼分點監控

監控每日台股（上市 `.TW` / 上櫃 `.TWO`）個股的**波段上漲前三大真主力分點目前持有張數、平均成本與獲利乖離、今日動作**，並在觸發大單賣出條件時推播 **Telegram 警示**。

## 核心設計邏輯

### 1. 動態波段觀察區間 ＋ 多週期交叉確認
- **區間起點**：找出過去約 `120` 個交易日內這波上漲前的最低點，再往前推 `30` 個交易日（可透過 `--pre-days` 或 `config.json` 調整於 `20～40` 日），把起漲前整理期的吃貨也包進來。
- **多週期交叉確認**：同時計算 `20`、`60`、`120` 日淨買超排名。三週期皆上榜的分點標記為 **★三週期共振真主力** 並獲得最高評分權重；僅在 20 日榜出現者則標示為短線資金。

### 2. 依個股行為排除隔日沖（不用固定黑名單）
針對每檔股票的候選分點獨立計算以下三項指標，**兩項以上（≥ 2 項）符合才在該股排除為隔日沖**：
- **淨買比**：`|淨買| ÷ (買 + 賣) < 0.20`
- **隔日反向率**：買超日之後隔一個交易日賣出達前日淨買 70% 以上的天數比例 `> 60%`
- **平均持有天數（FIFO）**：已週轉部位加權平均持有 `≤ 2.0` 個交易日

### 3. 地緣性主力（評分加分項）
- 於 `config.json` 的 `geo_brokers` 維護「股票代號 → 地緣分點關鍵字」對照表。
- 命中地緣且為波段淨買超者，評分加成 `35%`（小型股 `small_cap: true` 加成 `50%`），僅作排序加分而非唯一判定標準。

### 4. 每日監控「前三大主力」與 Telegram 大單賣出警示
每個主力分點每日輸出：
- **目前持有張數**：波段觀察區間內累計淨買超（已扣除後續賣出）。
- **平均成本 & 獲利乖離 (%)**：以分點每日買進張數與當日均價計算加權平均買價；若現價較成本高出 **> 30%**，標註出貨風險升高。
- **今日動作**：今日買賣超張數與占目前持有張數比例。

以下 **任一條成立** 即觸發大單賣出警示並可推播 Telegram：
1. 單日賣出 ≥ 持有張數的 `10%`
2. 單日賣出 ≥ 該分點 20 日平均成交量的 `2` 倍
3. 連續 `2` 天以上淨賣
4. 前三大中有 `2` 家同一天淨賣（共振出貨）

## 使用方式

```powershell
# 1. 依 config.json 監控清單執行
python main.py

# 2. 指定股票並匯出 CSV / JSON 至 reports/
python main.py 2330 6488 --export

# 3. 啟用 Telegram 推播（或於 config.json 設定 telegram.enabled=true）
$env:TELEGRAM_BOT_TOKEN="your_bot_token"
$env:TELEGRAM_CHAT_ID="your_chat_id"
python main.py --telegram

# 4. 每日盤後定時自動監控
python main.py --schedule 15:30 --telegram --export
```
